# MISHU

> BOSS直聘 个人自动化助手：
>
> - **自动投递**（`npm run watch`）：HR 向你发来招呼、你还没看过 → 自动回一份附件简历
> - **主动打招呼**（`npm run greet`）：从推荐岗位里挑和你匹配的 → 大模型逐条写开场白 → 主动联系 HR

---

## 安装

```bash
git clone https://github.com/jamesbow007/MISHU.git
cd MISHU
npm install
```

然后：

1. 打开 `chrome://extensions/`，右上角开启「开发者模式」
2. 点「加载已解压的扩展程序」，选项目里的 **`extension/`** 目录（图标亮着 = 已连上）
3. 用你日常那个 Chrome 登录 zhipin.com
4. 配一个大模型（只有「主动打招呼」需要）—— 任何 **OpenAI 兼容接口**都行：

```bash
cp .env.example .env
```

```
BASE_URL = "https://api.deepseek.com/v1"
API_KEY  = "sk-xxx"
MODEL    = "模型名"
```

## 自动投递

```bash
npm run watch
```

每 5 分钟扫一次「新招呼」里**带红点**的会话（红点 = 你还没点开过），自动发一份附件简历。
发送路径和你手动点「发简历 → 确定」一模一样，每一步都核对会话对没对上人，**对不上就停手**；
发完回服务端确认一次，确认到了才记「已投递」。同一个 HR 12 小时内不重复投。

| 参数 | 作用 |
|---|---|
| `--once` | 只跑一轮就退出 |
| `--dry-run` | 只扫描打印，一个不投 |
| `--limit N` | 本轮最多投 N 个 |
| `--bg` / `--stop` / `--status` | 后台跑 / 停掉 / 看状态 |

日志：`data/watch.log`。

## 主动打招呼

```bash
npm run greet -- --dry-run    # 先干跑：只打印挑了哪些岗位、开场白长什么样
npm run greet                  # 实跑，常驻，Ctrl+C 停
```

一轮的流程：

1. **找岗位** —— 只从职位页的**推荐区**抓（按你简历里的期望职位推荐的那批）
2. **逐个判断** —— 打开岗位详情页读 JD，交给大模型打分：匹配吗？值得打招呼吗？
3. **写开场白** —— 值得的，大模型**根据你简历的「个人优势」**单独写一句，一岗一句
4. **发出去** —— 在岗位页点「立即沟通」，只发**文字**；发完到服务端确认真的发出去了
5. **记账防重复** —— 按 **HR（人）** 去重：同一位 HR 30 天内不打扰（哪怕他挂了好几个岗位）

| 参数 | 作用 |
|---|---|
| `--once` | 只跑一轮 |
| `--dry-run` | 只看判断和文案，不发 |
| `--limit N` | 本轮最多打 N 个招呼 |
| `--pick <jobId>` | 只处理指定岗位（补投用） |

日志：`data/greet.log`（`tail -f` 实时跟）。

## 配置

没有配置文件就全用默认值。想改就在 `data/greet-config.json` 写一个 JSON：

| 字段 | 默认 | 含义 |
|---|---|---|
| `intervalMinSec` / `intervalMaxSec` | 120 / 300 | 两个招呼之间随机间隔（秒） |
| `perRound` | 20 | 每轮最多打几个（0 = 不限） |
| `dailyLimit` | 0 | 每天最多打几个（0 = 不限） |
| `cooldownDays` | 30 | 同一位 HR 多久之内不再打扰（天） |
| `candidates` | 30 | 一轮最多处理几个岗位（开页面 + 问模型） |
| `roundGapSec` | 300 | 两轮之间歇多久（秒） |
| `pages` | 1 | 每个期望职位翻几页推荐 |

判断结果缓存 24 小时 —— 重复推的岗位不会重复问模型、重复花钱。

## 常见问题

**「扩展未响应」**
Chrome 没开，或扩展被停用了 —— 到 `chrome://extensions/` 里点一下 🔄。

**浏览器里 BOSS 页面越开越多？**
正常只会留一个。先 `npm run watch -- --tabs` 看一眼，多了就 `--cleanup-tabs` 清掉。

**改了扩展代码没生效**
Chrome 缓存住了 —— 跑 `npm run ext:reload` 让扩展自己重载。
