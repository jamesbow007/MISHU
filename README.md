# MISHU

> **常驻自动投递**：后台挂着，每 5 分钟扫一次「新招呼」标签页里**带红点**的会话，
> 自动给这些 HR 发一份附件简历。

---

> ⚠️ **个人自用工具**
>
> - 请只用于**你自己账号**里的消息，遵守 BOSS直聘的用户协议 ——
>   自动化行为可能触发平台风控，**账号风险自负**
> - BOSS 每天打招呼/投递有次数上限，属于平台规则，本工具不绕过
> - 它只处理**你自己收到的**招呼，不群发、不替你回复消息

---

## 它认谁

只投「新招呼」标签页里**带红点**的会话。

红点 = 网页上那个小数字 = **你还没点开过这个对话框**（BOSS 的已读标记走长连接推送，
只有你亲手点开会话才会消掉）。所以它投的是「刚来、你还没看过」的 HR，
不会去打扰你之前已经聊过的人。

## 它怎么投

在聊天窗口点「发简历」→ 弹窗点「确定」—— 跟你手动发是一模一样的路径。

每一步都先核对：**打开的会话和目标对不上（同名 HR）就停手**，不会发出去。
发完还会回服务端确认一次：会话里确实出现了附件简历消息，才记成「已投递」。

- 投递数量不做限制 —— 有多少个红点就投多少个
- 失败（对方不支持发简历、弹窗出不来）**跳过并记进失败名单**，不重试、不中断整轮
- 同一个 HR 12 小时内不会重复投

## 安装

### 1. 拿代码 + 装依赖

```bash
git clone https://github.com/jamesbow007/MISHU.git
cd MISHU
npm install
```

### 2. 加载 Chrome 扩展

1. 打开 `chrome://extensions/`
2. 右上角开启「开发者模式」
3. 点「加载已解压的扩展程序」，选项目里的 **`extension/`** 目录
4. 扩展图标出现在工具栏（绿色数字徽章 = 已连上本地服务）

### 3. 登录 BOSS直聘

用你日常那个 Chrome，登录 zhipin.com。

> **不需要**手动开着消息页 —— 工具会自己在后台开一个、用完关掉。

## 用起来

```bash
npm run watch
```

**一条命令就够** —— 桥接进程它自己会拉起来，不用另外开。

前台每 5 分钟扫一轮。想让它脱离终端：

```bash
npm run watch:bg       # 后台跑
npm run watch:stop     # 停掉
npm run watch:status   # 看它还在不在跑、今日投了几个
```

| | `npm run watch` | `npm run watch:bg` |
|---|---|---|
| 终端 | 占着，关不掉 | 不占，关了也继续跑 |
| 日志 | 屏幕上实时滚 + 写文件 | 只写文件 |
| 停止 | `Ctrl+C` | `npm run watch:stop` |

### 先干跑看一眼

```bash
npm run watch -- --once --dry-run
```

只打印「这一轮会投给谁」，一个都不发。核对完名单再去掉 `--dry-run`。

### 常用参数

| 参数 | 作用 |
|---|---|
| `--once` | 只跑一轮就退出 |
| `--dry-run` | 只扫描打印，不投递 |
| `--interval N` | 轮询间隔（秒，默认 300 = 5 分钟） |
| `--limit N` | 本轮最多投 N 个 |
| `--only <姓名>` | 只投给指定的人（补投用） |
| `--no-verify` | 不做服务端二次确认（快一点，但少了自检） |
| `--tabs` | 列出浏览器里所有标签页（排查用） |
| `--cleanup-tabs` | 关掉多余的聊天页标签页（加 `--yes` 才真关） |

### 日志和状态

| 文件 | 内容 |
|---|---|
| `data/watch.log` | 运行日志，一行一条 |
| `data/auto-deliver-state.json` | 已投/失败名单（用来避免重复投） |
| `data/watch.pid` | 后台进程的 PID |

## 遇到问题

**「扩展未响应」**
扩展没连上。检查 Chrome 是否开着、`chrome://extensions/` 里扩展是否被停用
（被停用时点一下 🔄）。

**浏览器里是不是越开越多 BOSS 页面？**
守护进程需要自己养一个聊天页标签页（红点是页面通过长连接推给前端的，
页面关着就收不到）。正常情况下**只会留一个**。
先看一眼 `npm run watch -- --tabs`，多了就 `npm run watch -- --cleanup-tabs`。

**自动投递说「找不到新招呼 tab」**
BOSS 改版了，页面结构变了。

**投递失败 / 提示「不支持一键投递」**
猎头岗位不走一键投递，必须在聊天里发 —— 本工具走的就是聊天路径。
另外，账号里没上传过附件简历的话也发不了。

**会不会把我的未读洗掉？**
会 —— 但这是 BOSS 自己的机制：自动投递要投简历就得先打开会话，
那个会话的红点会随之消失。工具不会替你删任何消息。

**改了扩展代码没生效**
Chrome 把扩展资源缓存住了 —— 改完 `extension/` 下的文件，跑 `npm run ext:reload`
让扩展自己重载。

## 已知限制

- 需要一个**已经登录 BOSS直聘**的 Chrome
- 猎头岗位的岗位页没有投递按钮，投递只能从聊天窗口走
- 投完之后那个会话会离开「新招呼」标签页（发了消息 = 已经在沟通了），这是 BOSS 自己的行为。
  **别删投过的会话** —— 投递记录要等对方确认后才出现，删了就看不到对方接不接受了
- BOSS 改版可能导致页面结构变化
